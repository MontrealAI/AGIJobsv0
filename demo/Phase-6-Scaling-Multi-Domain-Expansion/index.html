FROM A BOUNDED TASK TO COMPOUNDING CAPABILITY

        
Scale what can be verified.

        

          

            
01 / Commission the worker

            

              The repository’s admitted Responses adapter can dispatch to an
              appropriately configured OpenClaw gateway. The gateway needs a
              protected worker profile, isolated browser or sandbox, explicit
              origins, action policy and enforced cost and time limits. A
              profile name alone connects nothing.
            

          

          

            
02 / Scope the computer work

            

              An operator-led ChatGPT Work session may use its available
              computer, browser, code and file tools under the user’s
              permissions. This repository does not expose a remote Work
              dispatch API or implement the separate OpenAI-hosted
              browser-session API. Tool availability and task reliability must
              be demonstrated for each workflow.
            

          

          

            
03 / Review independent evidence

            

              Keep the exact task, sources, action log, artifacts and runtime
              record. An independent reviewer reproduces the acceptance checks
              and records discrepancies. Hashes establish byte integrity;
              self-reported success and illustrative compliance scores do not
              establish correctness, eligibility or independent approval.
            

          

          

            
04 / Settle under actual authority

            

              A buyer accepts the useful deliverable. An authorized deployment
              and signer apply its real dispute, fee and settlement rules.
              Provider completion, independent review, buyer use and settlement
              are separate events with separate evidence.
