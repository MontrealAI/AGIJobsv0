02 / RECOMPUTED LEDGER

What the evidence supports

    Artifact review uses the same evaluator to recompute supplied input. Even a fully replaced, self-consistent bundle can pass. Its origin remains unverified.

    Read the three signals

    Criterion met: the supplied number satisfies its threshold. Held: a dependency is not ready. Ready for human review: the criterion is met and its dependencies are ready. None of these is approval or proven impact.

    Keep the exact evidence

    The bundle preserves packet, ledger, report and receipt bytes. Import recomputes the result and rejects changed output even if its receipt was rehashed. The last successful session is stored on this device when browser storage is available.
