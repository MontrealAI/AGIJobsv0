        Production acceptance requirements

        Governed Autonomy

        Before live execution, verify the actual owner, multisig, timelock and privileges on the target chain. These controls are not established by a local export.

        Verifiable Compute

        Check deliverables against approved source data with an independent evaluator. Commit-reveal and signed hashes are evidence mechanisms, not proof that the work is correct.

        Institutional Observability

        Commission monitoring against real chain and worker events, preserve journals, and rehearse interruption and recovery. This page displays saved local data.

        Operational UX

        Responsive dashboards, exact numbers, English/French interface labels and non-interactive CLI output support review. Scenario details and command output remain in English.
