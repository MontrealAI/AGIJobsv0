Retain exact original UTF-8 bytes and bind one mission revision, one stage and one logical commission identifier to exactly one selected currency route. A different route is a separate branch of the same frozen mission, with no currency conversion or shared balance.

The initial synthetic mode permits zero currency caps, zero reservations, no submission, no transaction, no external execution and no settlement authority. Reject unsupported schema, altered artifacts, stale context, mismatched route, nonzero money and imported authority. Expose unsupported/unprovisioned states rather than simulating submission. Import does not grant fresh capability acceptance.
