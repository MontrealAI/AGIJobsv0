## Check the exported package with this checkout

After downloading `successor-build-pack.json`, use the repository's supported Node.js version:

```sh
node scripts/pages/verify-successor-build.mjs /path/to/successor-build-pack.json
```

The verifier checks the package digest and canonical token, verifies every unsigned draft commitment,
recompiles the complete job graph using this checkout's compiler, and requires equality with the exported
compilation. It rejects altered terms, admitted jobs, forged authority and claimed settlement.

`MATCH` means historical consistency at the recorded creation time. It does not authenticate a producer,
prove the Alpha algorithm correct, establish fresh rights or grant current authority. It never broadcasts
transactions or changes job state.

## Maintenance

`website/successor-build/index.html` is a byte-for-byte mirror of Alpha's generated workshop. Its provenance
file identifies the canonical source path, engine identity, vendored Jobs revision and whole-page SHA-256.
The site build publishes it at `successor/build/` and includes that route in the site manifest/sitemap.
The page is self-contained; no remote application code is fetched at runtime.

Update the canonical Alpha templates, regenerate and validate there, then update the HTML and provenance
together. The site tests check the page digest, inline CSP hashes and agreement with the local deployment
directory. The source guide maps the four supplied SUCCESSOR publications to the implementation and explains
ownership, code licenses, full costs, independent evaluation, separate admission and renewal.
